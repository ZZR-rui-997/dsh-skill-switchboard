# dsh-skill-switchboard（技能开关台）

在 DSH Web 客户端的左侧栏加一个**技能开关台**：看你自己装的技能、开或关、全文搜索、按规范检查并一键修复、编辑 SKILL.md、新建、导入文件夹或 `.zip`、在用户/通用/项目三个根之间移动、打标签、删除到回收站还能恢复。

> 它只**操作你的技能文件**，不打包、不改动系统自带的技能。

## 安装

**作为 bundle（推荐）**

1. 打开 **插件 → 添加插件**，指向这个包，或在市场里直接安装。
2. 重启一次客户端，左侧栏出现**技能**入口。

**不使用 bundle 时**

这个插件由「客户端面板 + 宿主半」两部分组成，必须作为 bundle 安装；它没有"把 SKILL.md 丢进 `~/.dsh/skills` 就能用"的形态。

## 它显示哪些技能

只显示**你自己安装或编写**的技能：

| 根目录 | 优先级 | 作用范围 |
| --- | --- | --- |
| `<项目>/.dsh/skills` | 100 | 仅当前项目 |
| `<项目>/.agents/skills` | 200 | 仅当前项目 |
| `~/.dsh/skills` | 400 | 所有会话 |
| `~/.agents/skills` | 500 | 所有会话 |

用 junction / symlink 链过来的技能也会列出，并标记**链接**。系统自带与插件提供的技能**不在此列**——它们归各自包所有，只读。

## 能做什么

- **启用 / 停用** —— 一个开关把 `disable-model-invocation` 与 `user-invocable` 写回该技能 SKILL.md 的 frontmatter；文件系统提供器监听文件变化、自动重新发现，**无需重启**。写回时保留 BOM 与原换行符。
- **搜索** —— 名称、描述、正文全文，并可按 *全部 / 已启用 / 已停用 / 有规范问题 / 链接技能* 过滤。
- **检查 + 一键修复** —— 按 SKILL.md 规范检查（`name` 是否 kebab-case、`description` 是否为空、布尔开关取值、正文声明却缺失的文件），可一键修复能安全修的部分（规范化 frontmatter、把目录名改成与 `name` 一致）。
- **编辑** —— 弹窗里直接改 SKILL.md（上限 2 MB），按原编码写回。
- **新建** —— 在指定根目录建一个 kebab-case 技能，自动生成 frontmatter。
- **导入** —— 单个技能文件夹、装多个技能的父目录（批量），或 `.zip`（≤ 64 MB，安全解压）。导入前有**预检**：新增 / 重名 / 将覆盖各多少，确认后才复制。
- **移动** —— 在用户级、通用级、项目级之间挪动，内容原样保留。
- **标签** —— 每个技能最多 12 个标签（每个 ≤ 32 字符），存在 `~/.dsh/skills-panel/groups.json`。
- **删除 / 恢复** —— 删除是把技能挪进集中回收站（上限 100 条），不是销毁；回收站视图里可恢复。
- **记经验** —— 往技能的「经验附注」区追加一条带日期的记录；也可以让当前会话的 Agent 起草这条记录。
- **使用统计** —— 每个技能旁显示被**真实加载**的次数与最近使用时间（⚡3 · 2 天前），并可切到「常用」过滤。数据来自本机会话事件，只统计真实技能加载与工具调用，**不含子智能体**，最多保留 300 条。
- **检查更新** —— 拿技能的 `metadata.version` 和它声明的 GitHub 仓库比（只有你点这个按钮时才会联网）。
- **批量模式** —— 多选后一次性启用或停用。

## 边界与安全

- 所有宿主命令都是 `recordInput: false`：面板干的任何事都不会进入模型对话记录。
- 面板会**写你的技能文件**：开关、编辑器、修复、新建、导入、移动、标签、记经验都会落盘；删除走回收站，最多留 100 条。
- 删除与移动**拒绝 junction / symlink 根**，避免误把链接拨掉。
- 系统自带与插件提供的技能是只读的：不列出、也不能切换。
- 只有"检查更新"会联网，对象是 `api.github.com`；使用统计纯本机读写 `~/.dsh/skills-panel/usage.json`，不出网。
- 实测平台是 Windows；代码不调 shell，只用 `node:` 内置模块。
- 需要 DSH ≥ 0.2.2-rc.1、Node ≥ 22。

## 开发与自测

```bash
node --check index.js && node --check client.js
node tests/smoke.test.js
```

`tests/smoke.test.js` 会在沙箱里加载客户端与宿主两半、把插件 apply 到假 ctx，断言面板槽位与 `skills-panel-*` 命令都已注册，另含 locale 与打包不变量。
